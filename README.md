# MoviePilot-Plugins (montrush)

侯plus 家庭媒体库的 MoviePilot 插件市场仓库。

## 插件列表

| 插件 ID | 名称 | 版本 | 说明 |
|---------|------|------|------|
| AutoSubV2 | AI字幕自动生成(v2) | 3.1.0 | whisper 语音识别生成字幕 + 大模型翻译中文。MoviePilot V3 SDK 适配版，支持 strm 媒体库路径解析。基于 [lightolly/autosub](https://github.com/lightolly/MoviePilot-Plugins) → [chhc007 定制版](https://github.com/chhc007/moviepilot-plugin-autosubv2) → 本仓库 V3 适配 |

## 使用

MoviePilot → 设定 → 插件市场，添加本仓库地址：

```
https://github.com/montrush/MoviePilot-Plugins
```
